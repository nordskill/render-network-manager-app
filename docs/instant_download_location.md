# Instant Download Location

This field sets the default folder used by Instant Download while you are on the home screen (when logged-out). It gives you a quick way to control where link-based downloads go.

## How it works

When you paste direct download links or drop a TXT or CSV file into Instant Download, the app saves the files in your defualt system download folder unless you change it first.

---
### Important:

This location stays in sync with the app's main [default download location](settings_default_download_location.md), so changing it here updates this default setting for the entire app.
