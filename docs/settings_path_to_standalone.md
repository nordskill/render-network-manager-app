# Path to Octane Standalone

This setting points the app to your local Octane Standalone application.

## Why it matters

[Differential Upload](settings_differential_upload.md) for ORBX files needs the app to work with Octane Standalone locally when preparing ORBX scenes before uploading.

## How to set it up

Choose the actual launch file for Octane Standalone on your computer. The app checks whether the path works before keeping it.

If the app rejects the path, the file may be wrong or your local Octane installation may not be ready for use.
