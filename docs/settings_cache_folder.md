# Cache Folder

This setting chooses where the app keeps its temporary working files — not your final render output folder. This helps uploads, preview handling, and some download workflows run smoother.

If you move it, pick a fast drive with free space at least equal to the size of the scenes you plan to upload, especially when working with large ORBX files. 

## What goes there

The cache folder can hold temporary data used for things like:
- scene preparation before upload
- preview image cache
- temporary download staging files
