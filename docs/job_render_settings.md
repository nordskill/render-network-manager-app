# Render Settings

This section is where you control the main render options for the job.

These settings shape the final output quality, size, and render time. In most workflows, this is the section you review first after selecting a [preset](job_preset_selector.md).

## What you may see here

The exact fields depend on the scene type and selected render target, but they can include things like:

- resolution
- samples
- frame range
- shutter settings
- target-specific values from the source scene

## Good to know

When you create jobs from multiple render targets, these settings can either be shared across all targets or edited separately if you enable [individual target settings](job_render_individual_target_settings.md).
