# Individual Settings for Render Targets

This option lets you give each selected render target its own job settings.

Without this option, all selected render targets use one shared setup. With it turned on, the app creates separate tabs so you can adjust each target one by one.

## When to use it

Turn this on when targets need their own settings — for example, varying resolutions, frame ranges, quality settings, download locations, or network choices.

## Good to know

If you select mixed scene types, the app enables this automatically because one shared setup simply won't work across different render engines.
