# Outputs

This section shows the output formats available for the current job, preset, or reference settings.

Outputs define the files Render Network produces, such as PNG or EXR variants and related output settings.

## Good to know

Creating or changing output formats in the app is limited. If you need a specific output setup, create at least one job on the Render Network website with the exact output format you want. Then bring that setup back into the app by:

- creating a preset from that job
- or selecting that job as the reference when creating a new render
