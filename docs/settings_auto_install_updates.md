# Automatically Install Updates on App Restart

The app checks for new versions on every launch and downloads an available update in the background. This setting decides what happens with that downloaded update.

## Unchecked (default)

Nothing is installed on its own. The update stays downloaded, and the **Install update** button in the app updates panel remains available. Close and reopen the app as often as you like; the update is applied only when you click the button.

## Checked

The downloaded update is installed automatically the next time you close the app, even if you never click the **Install update** button.
