# Select Preset

This dropdown lets you choose the settings that will be used for the new job or jobs you are about to create.

This is the fastest way to avoid rebuilding render settings by hand. It is especially useful when you already have a job that rendered correctly and you want to repeat the same setup on a new scene.

## What you can choose

You can pick either:

- a saved preset
- an existing job, to reuse that job's settings as a starting point

## Good to know

If you change settings after choosing a preset or job, the configuration becomes custom for the current job.
