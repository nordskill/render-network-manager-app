# OB Score

OB Score is the OctaneBench score saved in App Settings. The Render Cost Calculator uses it to estimate how powerful your local machine is compared with the Render Network.

## How it works

Enter the OctaneBench score for the machine you use to test your scene. Once saved, the calculator can reuse this value automatically so you do not need to type it every time.

## Good to know

This setting only affects cost estimates. It does not change render quality, the selected Network tier, or the hardware used for the final render.

You can measure your score by running [OctaneBench](https://render.otoy.com/octanebench/) or approximate it from the [OctaneBench results table](https://render.otoy.com/octanebench/results.php).
