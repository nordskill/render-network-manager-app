# Focus on App When Job Starts via API

This option brings the app window to the front when a new job is started through the local API. For example, if you use the Cinema 4D Render Network Wizard, it submits jobs through this API, so you would see this behavior in action.

## When to use it

If you launch jobs from another tool or script, this makes it obvious that the Manager received the request and started working on it.

Use it if you depend on the local Render Network Manager's API and want instant visual confirmation inside the app.

Leave it off if you prefer the app to stay in the background while automation runs.
