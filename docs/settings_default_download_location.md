# Default Download Location

This is the main folder the app uses for downloads unless a job or workflow overrides it. Setting this once gives you a predictable place for all new downloads and reduces the need to choose a folder every time.

## What it affects

This default is used by:
- Instant Download
- any job that does not have its own custom download location

---
If a job is set to save next to the scene file, or if you choose a custom location inside a job, that job will ignore this default.
