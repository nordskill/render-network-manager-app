# Create Job Folder

This setting decides whether each download gets its own job folder.

- **When it is enabled**: The app creates one main folder for the job inside your chosen download location.
- **When it is disabled**: Files are saved directly into the download location itself.

Turning this on is usually cleaner for ongoing production work, especially if you download many jobs into the same place.
