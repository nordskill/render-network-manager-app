# Creating Output Formats

Output formats cannot be fully edited in the Render Network Manager during job creation.

## What to do instead

If you need a specific output setup, create at least one job on the Render Network website with the exact output format you want. Then bring that setup back into the app by:

- creating a preset from that job
- or selecting that job as the reference when creating a new render

Once you have one correctly configured job, you can reuse the same output setup again and again without rebuilding it every time.
