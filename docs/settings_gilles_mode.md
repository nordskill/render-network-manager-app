# Gilles Mode

Gilles Mode reduces the number of confirmation prompts shown by the app.

## Why artists use it

If you already know the workflow well, fewer confirmations will save you a bit of time and won't get in the way as often.

**Fun fact:** Gilles Mode is named after Gilles Augustijnen — the very first real user of the Render Network Manager app. This was his first feature request when he started using the application, so we named it after him.
