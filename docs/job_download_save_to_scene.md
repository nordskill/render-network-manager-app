# Save Next to Scene File

This option saves the downloaded render output in the same project location as the original scene you uploaded.

## What happens when it is enabled

The app uses the scene's folder instead of the custom [download location](job_download_location.md) field. That is why the folder picker becomes unavailable while this option is on.
