# Smart Folders

Smart Folders organize downloaded frames into a clearer folder structure.

- **When enabled:**  
  Files are sorted into folders based on output type and render pass, making large downloads easier to browse.
- **When disabled:**  
  All files are saved in a flatter layout, so the app relies on file names to show output and pass information.
