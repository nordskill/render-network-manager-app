# Passes

This section controls which render passes will be included for the job.

If the app is using the source file defaults, it keeps the passes already defined by the scene or the selected [preset](job_preset_selector.md).

## How to use it

If manual pass selection is available during job creation process, you can turn off the default behavior and choose only the passes you want.
