# Network and Costs

This section controls the job choices that affect cost, flexibility, and how the job behaves after frames are rendered.

## What you can set here

Depending on the job or preset, this section can include:

- the render tier
- payment type
- required VRAM
- maximum number of GPUs
- auto-approval for the frames
- auto-download

## Good to know

Auto-download depends on automatic frame approval. If frames need manual approval, the app cannot fully automate the download step.
