# Render Targets

This section lets you choose what scene render targets will actually be rendered. Here you decide whether to render only the default camera or take, or several named targets from the same project.

## The name depends on the scene type

The app adapts this section to the software you used:

- Octane scenes use "Render Targets"
- Cinema 4D scenes use "Takes"
- Blender scenes use "Scenes"

## How it works

Each selected target becomes its own render job. If you choose more than one target, the app can create multiple jobs in one step.

You can also specify [individual settings](job_render_individual_target_settings.md) for each render target if they need their own resolution, frame range, or other parameters.
