# Render Network Manager App

The Manager App acts as a bridge between 3D artist's local setup and the [Render Network](https://rendernetwork.com/ "Go to Render Network's website."), offering the same reliability as the web app but with added speed, organization, and direct-to-desktop control.

## Key advantages include:

* Differential uploads for faster re-renders
* Better scene and job management
* Drag-and-drop job creation
* Custom presets to streamline future submissions
* Local directory control for inputs and outputs
* A built-in render cost calculator
* Streamlined bridge capabilities to your DCC
